What can I upload?

A traffic dataset needs dated hourly vehicle counts. We recognize these common column names:

Date & time
DateTime, date_time, timestamp, or separate Date and Hour/Time.
Traffic count
traffic_volume, Vehicles, vehicle_count, traffic_count, or volume.
Optional inputs
Temperature, hourly rainfall/snowfall in mm, cloud cover in %, weather, and holiday. Missing columns are excluded from the model.
Multiple locations
We detect columns such as Junction or station_id and let you choose one location before training.

Use year-first local timestamps such as 2024-01-15 08:00:00. Each selected location needs at least 100 distinct recorded hours.

What the model uses

{% for label in data.feature_labels %}{{ label }}{% endfor %}

Time and weather categories are one-hot encoded, so each hour can have its own contribution. Numeric inputs use training-set median imputation and standardization.

Estimated volume = intercept + weighted input features

The date supplies calendar features. It does not supply real-time weather or a live traffic feed.

A reproducible path to prediction

One saved pipeline, shared by evaluation and the website.

  1. Prepare

    Preserve the source CSV, keep the first record per timestamp for the selected location, and sort by time. Available temperatures are converted to °C; implausible weather readings become missing values.

  2. Train

    Fit preprocessing and Linear Regression using the earliest {{ '{:,}'.format(data.split.train_count) }} hours. If a holiday column is present, its labels are converted to an indicator.

  3. Evaluate

    Measure MAE, RMSE, and R² on the latest {{ '{:,}'.format(data.split.test_count) }} hours. Compare with a training-mean baseline.

  4. Predict

    Load the saved pipeline, validate the inputs, and estimate vehicles/hour. Apply a zero lower bound; round only the displayed result.
